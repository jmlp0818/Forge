# Distribution status — checked 2026-10-24

Forge is distributed on GitHub as preview software. No Flathub submission has been made for this release. Do not label it store approved, verified, certified, or broadly tested.

Flathub's current requirements explicitly restrict host system utilities and applications requiring host components for core functionality. Forge's native package management, prerequisite installation, and host cleanup present significant eligibility questions. Broad host-command access also requires careful review.

Flathub now requires meaningful development history, real-world use, maintenance commitment and disclosure of AI-generated application materials. It prohibits AI-assisted Flathub manifests and AI-agent submission/review interactions. These restrictions cannot be solved by renaming a manifest or hiding provenance. The GitHub manifests here are AI-assisted and are not for submission.

A human maintainer must decide whether to seek eligibility guidance, independently write any permitted packaging and handle the submission/review personally. This document is a status record, not a submission message or a request for an AI review.

Sources:
- https://docs.flathub.org/docs/for-app-authors/requirements
- https://docs.flathub.org/docs/for-app-authors/metainfo-guidelines

Other stores require their own packages, terms and review. Publishing on GitHub does not list Forge in any other store.
